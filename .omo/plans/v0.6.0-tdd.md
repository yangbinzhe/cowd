# v0.6.0: 完全异步记忆 + 消除崩溃 — TDD 计划

## 目标

在 v0.5.3 基础上，将记忆系统和 TUI 全面异步化，**彻底消除** crash.log 中的 `enter_runtime` 条目。

## 当前 v0.5.3 基线

```
crash.log → 每次 turn 仍有 1 条 "Cannot start runtime from within runtime" (不致命)
catch_unwind → TUI 不死
456 + 132 = 588 测试通过
```

## 崩溃根因映射

| 崩溃源 | 位置 | 当前状态 | v0.6.0 方案 |
|--------|------|---------|------------|
| `record_turn_completed` | conversation.rs:1646 | `spawn_blocking` | 改为在 `run_turn_async` 中直接 `.await` |
| `stream_collect` | conversation.rs:95 | `Handle::current().block_on()` | 异步路径内替换为直接 stream 处理 |
| `TUI SHARED_RT.block_on` | main.rs:2830 | `catch_unwind` | 不再从 spawn 线程调用，消除原因 |

## TDD 分步计划

### Phase 1: 记忆系统完全异步

**目标**：`on_turn_end` 和 `stream_collect` 在异步路径中不使用任何 `block_on`。

#### T1.1: on_turn_end 在异步路径中直接 .await

**实现**：
- `run_turn_async` 中增加: `mgr.on_turn_end(&mut mem_messages).await`
- `record_turn_completed` 中移除 spawn_blocking（恢复 no-op 但不影响 session 持久化）

**测试**：
- `cargo test -p cowd-memory --lib` 456/456
- TUI turn 后 crash.log 条目减少（on_turn_end 不再触发 spawn_blocking crash）

#### T1.2: stream_collect 异步替代

**实现**：
- `run_turn_async` 中用 `self.api_client.stream().next().await` 循环替代 `stream_collect`
- `ApiClient::stream_collect` 保留用于 sync 路径（`run_turn` deprecated）

**测试**：
- `cargo build --release` 零错误
- TUI turn 正常执行

### Phase 2: TUI 不再 spawn 线程

**目标**：TUI turn 作为 SHARED_RT 的异步任务执行，消除跨线程 block_on。

#### T2.1: TUI turn → SHARED_RT.spawn

**实现**：
- 替换 `std::thread::spawn` + `catch_unwind` + `SHARED_RT.block_on`
- 使用 `SHARED_RT.spawn(async move { prepared.run_turn_async(...).await })`

**问题**：`run_turn_async` 返回的 future 非 Send（因为 `Pin<Box<dyn Stream>>`）。
**解决**：在 SHARED_RT.spawn 之前，用 `LocalSet::block_on(&*SHARED_RT, async { ... })`。

或者：修改 `ApiClient::stream()` 返回 `Pin<Box<dyn Stream + Send>>`。

### Phase 3: 回归验证

**目标**：crash.log 零增长。

**测试**：
- 连续 3 次 TUI turn，crash.log 行数不变
- `cargo build --release` 零警告
- `cargo test -p cowd-memory --lib` 456/456
- `cargo test -p api --lib` 132/132

---

## 执行顺序

```
T1.1 → T1.2 (消除内部 crash 源)
  ↓
T2.1 (消除外部 crash 源)
  ↓
Phase 3 (回归验证)
```

## 关键决策

- **不改变 `run_turn` (deprecated sync) 的 block_on 逻辑**——只有 TUI 使用 `run_turn_async`
- **不改 ApiClient trait 签名**——避免破坏所有 implementation
- **Memory 方法全部保持 async**——已完成的 cognitive.rs 异步化不回溯
