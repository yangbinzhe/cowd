# v0.6.x 完整重构执行计划 —— TDD · 可并行 · 明确目标

## 设计哲学

```
单 Runtime · 全异步 · 零崩溃 · 统一入口
```

四个核心原则：
1. **最高效的执行核心** — 一个 SHARED_RT 承载所有任务，零 Runtime 创建
2. **最强大的记忆框架** — 全异步 cognitive.rs，零 block_on
3. **最灵活的接入** — TUI / API / 平台共享 Session，统一管理
4. **最合理的全局设计** — 模块边界清晰，无分裂状态

## 当前 v0.6.1 基线

| 维度 | 状态 |
|------|------|
| Runtime | SHARED_RT 统一，TUI turn 用 std::thread::spawn + Runtime::new() |
| 崩溃 | catch_unwind 防护，每次 turn 1 条 crash 日志 |
| 记忆 | cross_store_verify async, on_turn_end async, MutexGuard 5 处已修 |
| 测试 | 456+132=588 通过 |

| 平台 | 飞书/企微/邮件仅骨架 |

**改动 2: main.rs TUI loop (lines 2715-2760 → 重写)**
```rust
// 当前 (~2715):
loop {
    drain_tui_events_state(&tui_rx, &mut state);
    // render
    if crossterm::event::poll(Duration::from_millis(poll_ms))? {
        let ev = crossterm::event::read()?;
        // keyboard/mouse handling...
    }
}

// 目标:
let mut reader = crossterm::event::EventStream::new();
loop {
    tokio::select! {
        Some(Ok(event)) = reader.next() => {
            // keyboard/mouse handling (same logic as current)
            // mouse scroll, key events → same code
        }
        _ = tokio::time::sleep(Duration::from_millis(16)) => {
            // tick: drain TUI events, check turn completion
            drain_tui_events_state(&tui_rx, &mut state);
            if turn_handle.as_ref().is_some_and(|h| h.is_finished()) {
                turn_handle = None;
                state.is_loading = false;
            }
        }
    }
    // render every iteration
    terminal.draw(|f| state.render(f))?;
}
```

### 数据结构 (crates/runtime/src/session_manager.rs)

```rust
pub type SessionId = String; // Uuid::new_v4().to_string()

pub struct SessionConfig {
    pub model: String,
    pub permission_mode: PermissionMode,
    pub system_prompt: Vec<String>,
    pub feature_config: RuntimeFeatureConfig,
}

pub struct SessionInfo {
    pub id: SessionId,
    pub model: String,
    pub created_at: chrono::DateTime<chrono::Utc>,
    pub last_activity: chrono::DateTime<chrono::Utc>,
    pub message_count: usize,
    pub token_count: u64,
    pub status: SessionStatus,
}

pub enum SessionStatus { Active, Suspended, Archived }

pub trait SessionManager: Send + Sync {
    fn create(&self, config: SessionConfig) -> Result<SessionId, SessionError>;
    fn get(&self, id: &SessionId) -> Option<Arc<ConversationRuntime>>;
    fn list(&self) -> Vec<SessionInfo>;
    fn info(&self, id: &SessionId) -> Option<SessionInfo>;
    fn suspend(&self, id: &SessionId) -> Result<(), SessionError>;
    fn resume(&self, id: &SessionId) -> Option<Arc<ConversationRuntime>>;
    fn archive(&self, id: &SessionId) -> Result<(), SessionError>;
    fn delete(&self, id: &SessionId) -> Result<(), SessionError>;
}

pub struct InMemorySessionManager {
    sessions: RwLock<HashMap<SessionId, SessionEntry>>,
}

struct SessionEntry {
    config: SessionConfig,
    runtime: Arc<ConversationRuntime>,
    info: SessionInfo,
}
```

### 每个方法的实现逻辑

| 方法 | 步骤 |
|------|------|
| `create(config)` | 1. 生成 Uuid → 2. 构建 Session + ConversationRuntime → 3. 存入 HashMap → 4. 返回 SessionId |
| `get(id)` | `sessions.read().get(id).map(\|e\| e.runtime.clone())` |
| `list()` | `sessions.read().values().map(\|e\| e.info.clone()).collect()` |
| `info(id)` | `sessions.read().get(id).map(\|e\| e.info.clone())` |
| `suspend(id)` | `sessions.write().get_mut(id).map(\|e\| e.info.status = Suspended)` |
| `resume(id)` | `sessions.write().get_mut(id).map(\|e\| { e.info.status = Active; e.runtime.clone() })` |
| `archive(id)` | `sessions.write().get_mut(id).map(\|e\| e.info.status = Archived)` |
| `delete(id)` | `sessions.write().remove(id)` → drop Arc → GC |

### 集成点

**TUI** (`main.rs`): `TuiState::new()` → 从 SessionManager 获取 Runtime → 替代直接创建 Session
**API** (`server/mod.rs`): handler → `session_mgr.get(&session_id)` → 替代直接创建 ConversationRuntime
