# v0.7.4 — 网关能力补齐 + 安装部署 TDD 方案

## TL;DR
> 补齐 v0.7.3 中标记的所有限制项，实现 API 完全对等、daemon 化、安装部署。
> 并行 Wave 执行，每个任务 RED→GREEN→REFACTOR 验证。

## Phase 1: API 能力对等 (连接实际后端) — 3 并行

### T1. Memory API → CognitiveContextManager [api_routes.rs + gateway.rs]
- ActiveSessions 增加 `memory_manager: Option<Arc<CognitiveContextManager>>`
- `/api/memory` 调用 `mgr.status()` 返回实时数据
- `/api/memory/search?q=xxx` 调用 `mgr.search()`
- `/api/memory/layers` 调用 `mgr.list_layers()`

### T2. Tools API → GlobalToolRegistry [api_routes.rs + gateway.rs]
- ActiveSessions 增加 `tool_registry: Arc<GlobalToolRegistry>`
- `/api/tools` 从 registry 读取实时工具列表
- `/api/tools/:name` 返回单个工具详情

### T3. Config API → ConfigLoader [api_routes.rs]
- `/api/config` 读取 `ConfigLoader::default_for(cwd).load()`
- `/api/config/:section` 返回特定配置段
- 敏感字段脱敏 (token, api_key)

## Phase 2: 安装部署 + 守护进程化 — 3 并行

### T4. cowd install 命令 [main.rs]
```
cowd install              → 复制二进制到 ~/.cowd/bin/cowd
cowd install --systemd    → 创建 + 启用 systemd 服务
cowd install --path /opt  → 自定义安装路径
cowd uninstall            → 移除二进制 + 服务
```

### T5. systemd unit 生成 [main.rs]
- 模板: `~/.cowd/cowd-gateway.service`
- ExecStart: ~/.cowd/bin/cowd gateway run
- 自动检测: systemctl --user 或 sudo

### T6. Gateway daemon 完善 [gateway.rs + server/mod.rs]
- PID 文件改为 `~/.cowd/gateway.pid` (不再 /tmp)
- 优雅关闭: SIGTERM → 清理 PID + 关闭 HTTP
- 健康检查: `/health` 端点已存在
