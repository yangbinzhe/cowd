# Task 4: ProviderPool empty-clients guard

## Problem
`provider_pool.rs:46` had `self.clients[idx].stream(request)` with `idx` computed as 
`self.current.load(Ordering::Relaxed) % self.clients.len().max(1)`. When clients was empty,
`.max(1)` made idx=0, then `self.clients[0]` panicked with index out of bounds.

## Fix
Added empty-guard between idx calculation and indexing:
```rust
if self.clients.is_empty() {
    return Box::pin(stream::once(async { Err(RuntimeError::new("ProviderPool: no clients configured")) }));
}
```

Also added `use futures::stream;` import for `stream::once`.
