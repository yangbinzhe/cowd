五层记忆系统

L0-L4 分层记忆架构，使用有界压缩、向量语义检索与 FTS5 关键词检索；压缩效果按实际内容和预算计量，不声明未验证的固定节省比例。

memoryfact-kernelMemoryOrchestratorContext CompressionCognitiveContextManager
  • L0 身份层 · L1 核心层(≤4000t) · L2 项目层(≤6000t) · L3 深度召回(搜索限制5) · L4 共享层
  • 有界压缩：保留关键规则、目标、决策和证据引用
  • 向量语义检索 (OpenAI/Ollama/vLLM) + FTS5 关键词双通道
  • 一致性过滤 (1000bp) + 矛盾检测 (Jaccard ≥ 0.6)
  • 自动后台提取 (30s, min_confidence 0.6)
  • 偏移检测：自动剪枝过期记忆 (staleness_decay)
  • MemoryPulse：从工作图自动生成记忆脉冲

sandboxsandbox_execSandboxConfigContainerEnvironment
