# v0.9.91 IACC Cockpit Projection

## Goal

Add the first personal/role cockpit projection for IACC. This version does not
build a visual UI yet. It creates the stable data product that dynamic pages,
templates, personal dashboards, and scheduled reports can consume.

The cockpit is generated from business operations state:

- focused attention;
- evidence and insight quality gates;
- governed action execution status;
- cross-plane bridge receipts;
- user/role focus and thresholds.

## Runtime Contracts

New contracts:

- `IaccCockpitProfileInput`
- `IaccCockpitProfile`
- `IaccCockpitWidget`
- `IaccCockpitProjection`

Profiles define:

- owner/person/role reference;
- focus entity refs;
- focus metric ids;
- threshold configuration;
- template id;
- report cadence.

Projection widgets currently include:

- `attention_queue`
- `quality_gate_status`
- `action_execution_status`
- `focus_thresholds`

## Store

IACC schema version is now `10`.

New table:

- `iacc_cockpit_profile`

New store capabilities:

- `upsert_cockpit_profile`
- `get_cockpit_profile`
- `cockpit_projection`

Health now reports:

- `cockpit_profile_count`

## API

New routes:

```text
POST /api/iacc/cockpit/profiles/upsert
GET  /api/iacc/cockpit/profiles/:id
GET  /api/iacc/cockpit/profiles/:id/projection
```

New health capabilities:

- `personal_cockpit_projection`
- `cockpit_profile_thresholds`

## Acceptance

Runtime tests prove:

1. profile persistence works;
2. projection filters attention by focused entity/metric;
3. projection includes quality gate counts;
4. projection includes active governed actions;
5. threshold widget is generated from profile configuration.

Scenario script:

```text
scripts/v0991_iacc_cockpit_projection_scenario.sh
```

The gateway scenario proves through API:

1. schema version 10 is exposed;
2. cockpit capabilities are visible;
3. IACC operational pipeline still produces attention, evidence, quality gates,
   incident analysis, and action execution;
4. a cockpit profile can be saved and retrieved;
5. projection returns the four expected widget types;
6. projection contains focused attention, pass quality gates, active actions,
   and configured thresholds.
