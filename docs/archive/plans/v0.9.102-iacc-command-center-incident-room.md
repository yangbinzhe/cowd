# v0.9.102 IACC Command Center and Incident Room

## Goal

Provide product-grade aggregation APIs for the IACC operating surface: a command center for current operational risk and an incident room for evidence, analysis, skills, actions, cases, playbooks, and agent graph state.

## Implemented Capabilities

- `GET /api/iacc/command-center`
  - health summary
  - hot risk queue
  - recent changes
  - skill count
  - operating lanes
- `GET /api/iacc/incidents/:id/room`
  - incident
  - evidence packet
  - quality gate
  - latest analysis
  - executions
  - memory cases
  - recommended playbooks
  - agent graph
- Health capabilities:
  - `command_center_projection`
  - `incident_room_projection`

## Acceptance

Run:

```bash
scripts/v09102_iacc_command_center_incident_room_scenario.sh
```

Expected result:

- command center returns risk queue and operating lanes
- incident room returns evidence, quality gate, analysis, execution, skill graph, and playbook context
