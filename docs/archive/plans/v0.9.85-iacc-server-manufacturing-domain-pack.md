# v0.9.85 IACC Server Manufacturing Domain Pack

## Goal

Add the first industry domain pack on top of the v0.9.84 entity/relation
network. The pack models discrete server manufacturing objects, relations,
metrics, and representative scenarios so later metric dependency, scale,
attribution, digital employee, and cockpit work has one shared business
substrate instead of isolated test data.

## New Runtime Contracts

New IACC contracts:

- `IaccDomainPack`
- `IaccDomainScenario`
- `IaccDomainSeedPlan`
- `IaccDomainSeedResult`

New functions:

- `server_manufacturing_domain_pack`
- `server_manufacturing_seed_plan`

## Domain Content

The server manufacturing pack defines:

- entity types for products, SKUs, BOM concepts, components, suppliers,
  purchase/order/manufacturing/quality objects, people, and organizations;
- relation types such as `requires`, `supplied_by`, `reserved_for`,
  `processed_at`, `affected_by`, and `quality_checked_by`;
- metric ids for material shortage, supplier commitment, work-center load,
  delivery risk, inventory coverage, first pass yield, quality escape, and
  revenue-at-risk;
- three initial scenarios:
  - GPU shortage affecting strategic AI server orders;
  - final assembly load overload;
  - DIMM quality issue affecting storage server shipment.

## Store

New store capability:

- `seed_server_manufacturing_domain`

The seed operation is idempotent because entity ids, relation triples, metric ids,
and fact ids are stable.

It creates:

- 14 canonical business entities;
- 13 typed relations;
- 6 metric definitions;
- 5 metric facts;
- 3 domain scenarios.

## API

New routes:

- `GET /api/iacc/domain/server-manufacturing`
- `POST /api/iacc/domain/server-manufacturing/seed`

`GET /api/iacc/health` now advertises:

- `server_manufacturing_domain_pack`
- `server_manufacturing_seed`

## Acceptance

Runtime tests prove:

- seed creates canonical entities, relations, metric definitions, and facts;
- PLM source key `GPU_H100_80GB` resolves to `entity-component-gpu-h100`;
- GPU component impact trace reaches the strategic customer order;
- metric recompute produces seeded manufacturing metric states and attention.

Scenario script:

```text
scripts/v0985_iacc_server_manufacturing_domain_scenario.sh
```

The scenario proves through the gateway API:

1. the domain pack is exposed;
2. seed result includes scenarios, entities, relations, metrics, and facts;
3. source-key resolution works for a manufacturing component;
4. impact path from GPU component reaches affected customer order;
5. seeded facts recompute into metrics and attention;
6. the existing action-feedback closed loop remains compatible with schema 6.
