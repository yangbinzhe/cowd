# v0.9.103 IACC Source Pack and Large Data Pilot

## Goal

Provide the first production data onboarding contract for IACC so source systems without stable APIs can still feed the operating layer through governed source packs.

## Implemented Capabilities

- Runtime models:
  - `IaccSourcePack`
  - `IaccSourceEntityMapping`
  - `IaccSourceFactMapping`
  - `IaccSourcePackValidation`
  - `IaccSourceDeltaPlan`
- Store support:
  - durable source pack table
  - source pack validation
  - delta plan based on fact mappings and metric dependency graph
- API routes:
  - `POST /api/iacc/source-packs/upsert`
  - `GET /api/iacc/source-packs/:id`
  - `POST /api/iacc/source-packs/:id/validate`
  - `POST /api/iacc/source-packs/:id/ingest-file`
  - `POST /api/iacc/source-packs/:id/delta-plan`
- Health capabilities:
  - `source_onboarding_pack`
  - `source_pack_delta_plan`

## Boundary

This version does not implement binary file upload or a production warehouse adapter. It establishes the structured source onboarding contract and a JSON-file style ingestion route that can represent batch exports, DB views, RPA exports, and manual uploads.

## Acceptance

Run:

```bash
scripts/v09103_iacc_source_pack_large_data_scenario.sh
```

Expected result:

- source pack upsert/get/validate works
- source pack ingest-file inserts facts
- delta plan resolves affected metric ids
- scoped compute job can run from the ingested facts
