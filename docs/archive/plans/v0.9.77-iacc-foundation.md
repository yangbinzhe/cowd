# v0.9.77 IACC Foundation

## 目标

建立 IACC 在 Cowd 最新 AI 基座上的第一层稳定扩展点，为后续结构化运营认知、指标网络、证据包、数字员工和闭环执行打基础。

本版本只做 Foundation，不进入完整制造行业模型和驾驶舱产品化。

## 实施内容

- 工作区版本号从 `0.9.76` 提升到 `0.9.77`。
- 新增 `runtime::iacc` 模块，提供 IACC 结构化运营认知的基础契约：
  - `IaccSourceSnapshot`
  - `IaccFact`
  - `IaccFactInput`
  - `IaccAttentionItem`
  - `IaccEvidencePacket`
  - `IaccStore`
- 新增 `.cowd/iacc.sqlite` 独立 SQLite store。
- 新增最小表：
  - `iacc_schema`
  - `iacc_fact`
  - `iacc_attention_item`
  - `iacc_evidence_packet`
- 新增 IACC HTTP API：
  - `GET /api/iacc/health`
  - `POST /api/iacc/facts/ingest`
  - `GET /api/iacc/attention/hot`
  - `POST /api/iacc/evidence/build`
  - `GET /api/iacc/evidence/:id`
- 新增真实 gateway 场景脚本：
  - `scripts/v0977_iacc_foundation_scenario.sh`

## 架构边界

本版本严格保持 IACC 的低冲突接入：

- 不修改 connector/resource directory schema。
- 不修改 memory runtime schema。
- 不修改 cross-plane policy 语义。
- 不修改 daemon socket protocol。
- 不改 WebUI 面板结构。

IACC 数据独立存放在：

```text
.cowd/iacc.sqlite
```

## 能力链路

本版本打通的最小链路是：

```text
Fact ingest
-> Foundation attention item
-> EvidencePacket build
-> EvidencePacket fetch
```

其中 attention item 目前只是 foundation placeholder，用于承接后续 `v0.9.78` 的 metric/change/attention 引擎。
