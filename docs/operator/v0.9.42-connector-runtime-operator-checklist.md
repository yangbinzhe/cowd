# v0.9.42 Connector Runtime Operator Checklist

## Purpose

This checklist verifies that a Cowd daemon can expose runtime state, session coordination, connector capabilities, cross-plane governance, and UI projections without relying on ad-hoc logs.

## Startup

1. Start the daemon:

   ```bash
   cowd gateway run
   ```

2. Confirm health:

   ```bash
   curl -fsS http://127.0.0.1:8642/health
   ```

3. Confirm runtime control-plane:

   ```bash
   curl -fsS http://127.0.0.1:8642/api/runtime/control-plane
   ```

Expected:

- `kind` is `runtime_control_plane`.
- `components.session.source_of_truth` is `sqlite` when the unified store is attached.
- `components.session.leases.status` is `available` when lease registry is attached.
- `components.connectors.summary.capability_count` is non-zero.
- `readiness.blocked` explains any missing production dependency.

## Connector Contract

Check these endpoints:

```bash
curl -fsS http://127.0.0.1:8642/api/connectors/summary
curl -fsS http://127.0.0.1:8642/api/connectors/accounts
curl -fsS http://127.0.0.1:8642/api/connectors/capabilities
curl -fsS 'http://127.0.0.1:8642/api/connectors/resources?limit=100&offset=0'
```

Expected:

- `mock.docs` is available as a local read-only service account.
- Feishu appears as ready only when required key fields and read scopes are configured.
- MCP servers appear from `mcpServers` config without blocking control-plane inspection on live discovery.
- Resource pages clamp large `limit` requests to the configured maximum.

## Governance

For any cross-plane service or channel action, confirm the chain:

- identity binding exists or resolves from the incoming identity ref
- grant exists for the requested capability when policy requires it
- policy simulation/preflight returns evidence
- execution receipt records mode, status, dispatch state, blockers, and idempotency key
- audit record includes connector context when a connector capability is involved

Core endpoints:

```bash
curl -fsS http://127.0.0.1:8642/api/cross-plane/summary
curl -fsS http://127.0.0.1:8642/api/cross-plane/identities
curl -fsS http://127.0.0.1:8642/api/cross-plane/grants
curl -fsS http://127.0.0.1:8642/api/cross-plane/audit
curl -fsS http://127.0.0.1:8642/api/cross-plane/action/executions
```

## Feishu Read-only Setup

Feishu workspace service capabilities are read-only. They should persist canonical resource refs only after account readiness and policy allow execution.

Minimum config requirements:

- platform type `feishu`
- app id
- app secret
- read scopes for the intended service:
  - `docx:read`
  - `drive:read`
  - `wiki:read`

Do not treat missing Feishu config as a daemon failure. It should appear as disabled or degraded with a clear missing-field reason.

## UI Verification

TUI:

- Gateway panel shows connector summary, account readiness, capabilities, resources, degraded reasons, and management endpoints.
- Command palette includes connector runtime actions.
- Session/runtime status remains available after TUI exit because daemon state is independent.

WebUI:

- Runtime Console shows control-plane status, readiness, degraded/blocked reasons, and session lease state.
- Connector Console shows accounts, capabilities, resources, service tools, service execution result, and receipts/audit.
- WebUI should project API state rather than keeping a separate connector model.

## Cleanup Checks

After scenario tests:

```bash
tmux ls 2>/dev/null | rg 'cowd-|webui-' || true
ss -ltnp | rg ':(18642|18643|18652|18662|18663|18664|18665|18666|18667|18668|18669|18670|8642)\b' || true
```

Expected output is empty unless a manually started daemon is intentionally running.

## Known Boundaries

- Feishu read-only connector currently persists resource refs and metadata; it does not ingest full document bodies into context by default.
- Playwright may require `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/snap/bin/chromium` on machines without Playwright-managed browsers.
- `runtime_control` tracing tests should run with `--test-threads=1` because they validate process-global tracing capture.
