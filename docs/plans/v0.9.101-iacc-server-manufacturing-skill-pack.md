# v0.9.101 IACC Server Manufacturing Skill Pack

## Goal

Turn generic IACC agent graph nodes into domain-specific server manufacturing digital employees with explicit input facts, metric keys, evidence requirements, tools, output actions, quality gates, and success criteria.

## Implemented Capabilities

- Added `IaccSkillManifest`, `IaccSkillPlan`, and `IaccSkillRun`.
- Added seven server manufacturing skills:
  - `supply-risk-analyst`
  - `material-clear-to-build-analyst`
  - `capacity-risk-analyst`
  - `quality-trace-analyst`
  - `delivery-risk-analyst`
  - `procurement-coordinator`
  - `plan-change-impact-analyst`
- Added skill discovery and incident planning APIs:
  - `GET /api/iacc/skills`
  - `GET /api/iacc/skills/:id`
  - `POST /api/iacc/incidents/:id/skills/plan`
  - `POST /api/iacc/incidents/:id/skills/:skill_id/run`
- Skill planning writes selected skills into the incident task's `AgentRunGraph`.
- Skill run marks the corresponding skill node completed and records run evidence.

## Acceptance

Run:

```bash
scripts/v09101_iacc_digital_employee_skill_pack_scenario.sh
```

Expected result:

- health exposes `server_manufacturing_skill_pack` and `incident_skill_agent_graph`
- skill list includes `supply-risk-analyst`
- incident skill planning selects supply/material skills from shortage evidence
- AgentRunGraph contains planned skill nodes
- skill run completes the node and returns recommended governed actions
