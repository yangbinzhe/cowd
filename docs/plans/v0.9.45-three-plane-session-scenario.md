# v0.9.45 Three-plane Same-session Scenario Gate

## Goal

Close the same-session verification gap between daemon runtime, HTTP API, and WebUI operator surfaces.

## Scope

- WebUI connector service execution uses the active `Api.sid` instead of an isolated placeholder session.
- A live Playwright scenario starts a real gateway in tmux, creates a session, acquires a runtime lease, executes a connector service, and verifies Runtime Console plus Connector Console projection from the browser.
- The scenario checks persisted connector resources and action receipts after browser execution.
