# v0.9.71 Multi-Agent Kernel

## Target

Move multi-agent support from loose task projection to a typed, traceable graph contract:

- planner/executor/researcher/reviewer/merger roles.
- dependency-aware task nodes.
- evidence references attached to nodes.
- review verdicts that can accept, challenge, or reject.
- merge decisions with explicit conflicts.
- API and WebUI projection for audit and coordination.

## Implemented

- Added runtime `agent_protocol` types.
- Added runtime `agent_kernel::AgentRunGraph` pure model.
- Added cycle detection, dependency readiness, node failure isolation, review, evidence, and merge decision APIs.
- Extended `TaskRecord` with persisted `agent_graph`.
- Mapped task phase/artifact/review/failure updates into the graph.
- Added `/api/agents/runs`.
- Added `/api/tasks/:id/agent-graph` read/upsert.
- Added WebUI API methods and Agents panel graph projection.
- Added live daemon scenario for HTTP task-to-agent-graph contract.
