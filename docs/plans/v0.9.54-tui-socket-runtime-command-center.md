# v0.9.54 TUI Socket Runtime Command Center

## Goal

Make the TUI control center use the local daemon Unix socket as its primary fast path for runtime/session/lease state, keeping HTTP as an optional projection channel for WebUI parity and lower-frequency resource views.

## Scope

- Add daemon socket command `runtime_snapshot`.
- Include daemon status, sessions, session leases, and transport policy in one local IPC response.
- Add `DaemonControlClient::runtime_snapshot`.
- Make `refresh_runtime_control_snapshot` prefer the socket snapshot, falling back to legacy `status + list_sessions` only when needed.
- Preserve HTTP projection enrichment for tasks, approvals, memory, context, connectors, and MCP.

## Validation

- `cargo test -p cowd-cli runtime_snapshot_reads_sessions_and_leases --no-default-features`
