# v0.9.53 MCP Bounded Probe Contract

## Goal

Make MCP operator readiness more explicit without allowing live discovery to block or destabilize the daemon control plane.

## Scope

- Add `GET /api/connectors/mcp/servers?probe=true&timeout_ms=N`.
- Clamp probe timeout to `50..=2000ms`.
- Run bounded HTTP probes only for URL-based transports.
- Do not spawn stdio/sdk MCP processes from the readiness endpoint; report them as `config_only`.
- Keep secrets out of all responses.

## Validation

- `cargo test -p cowd-cli connector_routes_project_configured_mcp_servers_into_runtime_contract --no-default-features`
- `cargo fmt --check`
- `git diff --check`
