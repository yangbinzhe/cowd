# v0.9.32 ResourceDirectory Minimal Closure

## Version Goal

Close the first Resource Plane loop: service execution produces an `ExternalResourceRef`, and the connector runtime stores it in a queryable directory.

## Scope

- Add lightweight `ResourceDirectory`.
- Support upsert/get/search/list_recent.
- Back `/api/connectors/resources` with the directory.
- Upsert mock docs service result resources.

## Non-goals

- No persistent database yet.
- No memory/context injection yet.
- No large-document indexing.

## TDD Plan

- Runtime directory upsert/search/list tests.
- Mock docs execute upserts a resource.
- Connector resources route returns the created resource.

## Acceptance

- `cargo test -p runtime connector`
- `cargo test -p cowd-cli mock_docs`
- `cargo test -p cowd-cli connector`
