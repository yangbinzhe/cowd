# v0.8.80 Cross-Plane TUI Execution Visibility

## Goal

Bring TUI Gateway visibility in line with WebUI for cross-plane execution.
Operators should be able to inspect dispatch capability and recent execution
state without leaving the terminal.

## Design

- Add lightweight TUI summary structs for adapter capabilities and execution
  receipts.
- Render adapter support as platform, operation, live/plan support, and binding
  state.
- Render execution receipt status, dispatch status, mode, capability, and
  idempotency key.
- Add the adapter and execution endpoints to the Gateway endpoint list.

## Acceptance

- GatewayPanel can render adapter capability state.
- GatewayPanel can render execution receipt state.
- GatewayPanel lists the new cross-plane execution management endpoints.
- Existing Gateway rendering and key handling remain stable.
