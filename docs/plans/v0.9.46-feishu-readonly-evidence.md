# v0.9.46 Feishu Read-only Evidence Closure

## Goal

Make Feishu read-only resources usable as governed evidence without silently implying that document body content has entered runtime context.

## Scope

- Feishu readonly execution returns machine-readable `body_policy`, `retrieval_capability`, and `next_actions`.
- Evidence resolution exposes the same metadata-only contract for persisted Feishu resources.
- Context resource injection marks Feishu resources as metadata-only and directs body access back through authorized connector capabilities.
