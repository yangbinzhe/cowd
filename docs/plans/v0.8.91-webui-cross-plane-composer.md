# v0.8.91 WebUI Cross-Plane Composer

## Goal

Expose the typed cross-plane dispatch backend in the WebUI gateway panel so the
operator can compose text, image, and file actions from one audited control
surface.

## Design

- Keep the Gateway panel operational and compact.
- Add an inline action composer instead of a modal.
- Generate the same action contract used by the API:
  `requested_capability`, `target_ref`, `resource_ref`, risk, trust, and mode.
- Support `send_text`, `send_image`, and `send_file`.
- Preserve preflight before execution and display dispatch target/outcome
  evidence inline.

## Implemented

- Replaced the hard-coded Feishu preflight demo with an action composer.
- Added operation, mode, principal, target, and payload controls.
- Added payload reference normalization:
  - text: `text://...`
  - image: `image://...`
  - file: `file://...` or workspace refs
- Added preflight and execute buttons that render target/outcome evidence.
- Added WebUI tests for typed media preflight and execute request contracts.

## Validation
