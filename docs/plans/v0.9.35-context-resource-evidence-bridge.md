# v0.9.35 Context Resource Evidence Bridge

## Goal

Use connector resources as context evidence without injecting large external resource bodies into the active model context.

## Delivered

- Context current API reads an existing durable `ResourceDirectory` and adds matching resources as `Workspace` evidence items.
- Resource context items include title, canonical ref, provider, resource type, and indexed state only.
- Stale/degraded resources carry an explicit warning in context.
- Evidence resolver supports `service://...` and `mcp://...` refs and returns metadata-only resource evidence.
- Existing behavior is unchanged when a workspace has no resource directory.

## Validation

- `cargo test -p cowd-cli context_current`
- `cargo test -p cowd-cli evidence_resolver`
- `cargo test -p cowd-cli connector`
- `cargo fmt --check`
- `git diff --check`

## Design Notes

- This bridge keeps resource bodies behind connector capabilities.
- Context receives references and summaries/metadata, preserving stable-head cache behavior and avoiding accidental large-document injection.
