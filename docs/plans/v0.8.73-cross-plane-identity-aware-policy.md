# v0.8.73 Cross-Plane Identity-Aware Policy

## Goal

Wire identity resolution into policy execution so channel callers do not need to
manually map an external identity into a canonical principal before simulation
or approval.

## Scope

- Add optional `actor_identity_ref` to cross-plane actions.
- Resolve action identity before grant matching and policy evaluation.
- Preserve compatibility through the existing `decide_and_audit` method.
- Add `decide_and_audit_with_action` for callers that need the evaluated action.
- Return the evaluated action from the policy simulation endpoint.

## Acceptance

- A high-risk action with empty `actor_principal` can be allowed when
  `actor_identity_ref` resolves to a principal with a matching grant.
- The audit action stores the resolved principal and trust.
- Decision evidence records the resolved identity.
- Existing action callers that do not pass `actor_identity_ref` keep the old
  behavior.

## Validation

- Runtime unit test covers identity-aware policy execution.
- API test covers HTTP policy simulation with identity resolution.
- Release gate must pass before commit.
