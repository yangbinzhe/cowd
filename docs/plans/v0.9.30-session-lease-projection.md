# v0.9.30 Session Lease Projection

## Version Goal

Make daemon session lease state visible and controllable through the HTTP runtime control-plane, so TUI, WebUI, and daemon clients share one observable collaboration contract.

## Scope

- Inject the daemon `SessionLeaseRegistry` into API state.
- Expose:
  - `GET /api/runtime/session-leases`
  - `POST /api/runtime/session-leases/acquire`
  - `POST /api/runtime/session-leases/release`
- Add lease projection to `GET /api/runtime/control-plane` under `components.session.leases`.
- Preserve existing Unix socket acquire/release behavior.

## Non-goals

- No lease TTL policy yet.
- No WebUI visual control changes yet.
- No TUI layout change yet.

## TDD Plan

- Registry list returns deterministic active lease projection.
- HTTP acquire/release routes operate on the same registry.
- Runtime control-plane includes active leases when attached.
- No-registry test mode returns `status: unavailable` instead of failing.
