# v0.9.48 Resource Lifecycle And Revalidation

## Goal

Give operators a direct lifecycle control for connector resources so stale or verified resources can be marked without database surgery.

## Scope

- Add `POST /api/connectors/resources/revalidate` for `indexed` and `stale` state transitions.
- Add WebUI resource row actions for `Mark indexed` and `Mark stale`.
- Keep operation bounded to the resource directory; no live external fetch is triggered.
