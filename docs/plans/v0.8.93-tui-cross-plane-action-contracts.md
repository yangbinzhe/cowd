# v0.8.93 TUI Cross-Plane Action Contracts

Status: implemented
Branch: develop

## Goal

Align the TUI Gateway panel with the WebUI cross-plane composer at the capability-contract level. The TUI should show the same typed action surface for text, image, and file dispatch without introducing asynchronous side effects into the current synchronous panel component.

## Design

- Keep GatewayPanel as a status and operator-readiness surface.
- Add an Action Composer Contract section that exposes:
  - preflight and execute API routes;
  - `channel.feishu.send_text`;
  - `channel.feishu.send_image`;
  - `channel.feishu.send_file`;
  - canonical resource references for `text://`, `image://`, and `workspace://file/`.
- Make the contract visible even when no live adapter is bound, so TUI users can understand the available control-plane shape before credentials or daemon state are ready.
- Defer active TUI dispatch execution to a later command/action pipeline stage, where async API calls can be injected without coupling GatewayPanel to networking.

## Acceptance

- TUI GatewayPanel renders the typed cross-plane action contracts.
- The canonical workspace file reference matches WebUI and backend dispatch behavior.
- Existing Gateway status, adapter, receipt, target, endpoint, and key-hint rendering remains intact.
- TUI component tests cover the new section.
