# v0.9.75 Release/Test Closure

## Goal

Close the release reliability gap where code can compile but the installed product, daemon, TUI, WebUI, session runtime, memory runtime, and channel permission runtime are not proven together.

## Runtime Contract

- Build the debug binary once with a controlled target directory.
- Install the built binary and static WebUI into `~/AI/cowd-debug-<version>-<timestamp>`.
- Optionally update `~/AI/cowd-debug-current` for local use.
- Start the installed binary through `gateway run` in `tmux`.
- Verify HTTP health, WebUI static serving, daemon socket control, same-session runtime visibility, memory runtime wiring, connector service execution, and cross-plane permission grant consumption.
- Kill all scenario `tmux` sessions and remove temporary workspaces after validation.

## Validation Commands

- `scripts/validate_release.sh`
- `scripts/scenario_full_product_smoke.sh <install-dir>`
- `scripts/install_debug_to_ai.sh --current`
- `scripts/report_release_artifacts.sh <install-dir> <report.md>`

## Acceptance

- `scripts/validate_release.sh` exits `0`.
- A runnable debug install exists under `~/AI`.
- `~/AI/cowd-debug-current/bin/cowd` can start the gateway.
- The release report contains step status, elapsed time, target size before and after, install path, and artifact size details.
- The release smoke covers WebUI access, daemon socket attach, session lease, task start, context query, memory runtime, connector execution, and cross-plane audit evidence.
