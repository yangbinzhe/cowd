# v0.9.44 TUI Connector Action Console Foundation

## Goal

Move TUI connector support from pure projection toward real daemon-backed operation by adding connector service tool discovery and execution to the TUI HTTP projection client.

## Changes

- Added `DaemonProjectionClient::connector_service_tools(service)`.
- Added `DaemonProjectionClient::execute_connector_service(service, request)`.
- Added route-contract tests for:
  - `GET /api/connectors/services/mock.docs/tools`
  - `POST /api/connectors/services/mock.docs/execute`

## Acceptance

- TUI-side code can call daemon connector management APIs without using service internals.
- Service execution stays behind daemon governance, receipt, audit, and resource persistence routes.
- Future Gateway panel/command palette executor work can use these methods directly.

## Validation

```bash
cargo test -p cowd-cli projection_client --no-default-features
cargo fmt --check
git diff --check
```
