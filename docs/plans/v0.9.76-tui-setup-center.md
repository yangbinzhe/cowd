# v0.9.76 TUI Setup Center

## Goal

Make setup simple for real use: one safe command, sensible defaults, no secret output, and clear next actions for channels and runtime.

## Scope

- Add `cowd setup`.
- Add `/setup` for TUI and resume-safe use.
- Add command palette entry: `Open Setup Center`.
- Report readiness for config, model provider, gateway/WebUI, Feishu, WeChat QR, memory, session store, and permissions.
- Keep setup read-only except for explicit follow-up commands such as `cowd gateway wechat-qr`.

## UX Contract

- New users see one next action instead of a raw config dump.
- Existing users can re-run setup without changing state.
- Credentials are never printed.
- Debug builds are considered valid.

## Acceptance

- `cowd setup` prints a readable readiness report.
- `cowd --output-format json setup` returns redacted structured JSON.
- `/setup` works in TUI/resume.
- `/help` lists `/setup`.
- Command palette exposes setup.
- Existing validation gates continue to pass.
