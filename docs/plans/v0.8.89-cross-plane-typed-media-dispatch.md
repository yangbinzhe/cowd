# v0.8.89 Cross-Plane Typed Media Dispatch

## Goal

Close the gap between declared channel capabilities and live dispatch behavior.
Before this version, cross-plane policy and channel metadata exposed
`send_image` and `send_file`, but commit execution only dispatched `send_text`.
That made permissions and UI capability surfaces stronger than the runtime path.

## Design

- Add a typed outbound payload contract at the platform runtime boundary:
  `Text`, `Image`, and `File`.
- Keep text dispatch compatible through `dispatch_outbound`, but route all commit
  execution through `dispatch_payload`.
- Keep cross-plane receipts explicit: operation, payload kind, payload ref,
  session key, dispatch status, and provider message id when available.
- Do not bury image/file payloads inside text execution. `text` remains as a
  legacy/display field; runtime dispatch uses `payload_kind` and `payload_ref`.
- Preserve graceful failure: unsupported adapter operations still produce a
  failed dispatch outcome instead of crashing the request path.

## Implemented

- `OutboundPayloadKind` and `OutboundDispatch` were added to the platform layer.
- `PlatformRuntime::dispatch_payload` now dispatches:
  - text via `PlatformAdapter::send`
  - URL images via `send_image`
  - local images via `send_image_file`
  - files via `send_document`
- `CrossPlaneOutboundMessagePlan` now carries `payload_kind`, `payload_ref`,
  `caption`, and `file_name`.
- `/api/cross-plane/action/execute` commit mode now executes ready media/file
  targets through the runtime dispatch path.
- API and runtime tests cover image/file plan generation and live image dispatch.

## Validation

- `cargo fmt --all`
- `cargo test -p runtime dispatch_ -- --nocapture`
- `cargo test -p cowd-cli cross_plane_execute_commit_dispatches_ready_image_target -- --nocapture`

## Remaining Follow-Up

- Return provider message ids for Feishu typed media sends when Feishu typed
  message APIs expose them through the helper path.
- Add WebUI/TUI affordances for composing media/file cross-plane actions.
- Add explicit local file safety policy before allowing arbitrary workspace file
  dispatch from user-facing surfaces.
