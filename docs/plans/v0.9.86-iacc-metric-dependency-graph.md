# v0.9.86 IACC Metric Dependency Graph

## Goal

Add the metric dependency graph required by the v0.6 roadmap. IACC now knows not
only which metrics exist, but how upstream metrics, downstream metrics, required
fact types, and entity relations connect. This is the foundation for incremental
compute, impact propagation, attention quality, and evidence lineage.

## Runtime Contracts

New contracts:

- `IaccMetricDependency`
- `IaccMetricDependencyInput`
- `IaccMetricLineage`

## Store

Schema version is now `7`.

New table:

- `iacc_metric_dependency`

New store capabilities:

- `upsert_metric_dependency`
- `metric_lineage`
- `metrics_affected_by_fact_type`

The server manufacturing domain seed now also creates five metric dependencies:

- supplier commitment -> material shortage risk;
- material shortage risk -> order delivery risk;
- work center load -> order delivery risk;
- first pass yield -> quality escape risk;
- quality escape risk -> order delivery risk.

## API

New routes:

- `POST /api/iacc/metric-dependencies/upsert`
- `POST /api/iacc/metric-dependencies/affected-by-fact-type`
- `GET /api/iacc/metrics/:id/lineage`

`GET /api/iacc/health` now returns:

- `metric_dependency_count`

New health capabilities:

- `metric_dependency_graph`
- `metric_lineage`
- `fact_type_metric_impact`

## Acceptance

Runtime tests prove:

- server manufacturing seed creates five metric dependencies;
- supplier commitment lineage reaches material shortage and order delivery risk;
- fact type `supply.commit_variance` maps to affected upstream and downstream metrics.

Scenario script:

```text
scripts/v0986_iacc_metric_dependency_graph_scenario.sh
```

The scenario proves through gateway API:

1. schema version 7 is exposed;
2. metric graph capabilities are visible;
3. server manufacturing seed creates metric dependencies;
4. metric lineage for `supplier_commit_variance` reaches `order_delivery_risk`;
5. fact type impact lookup returns both direct and downstream metrics;
6. manual dependency upsert is accepted and visible through lineage.
