# v0.8.68 Context Mode Coverage And Cache Stability

## Goal

Close the highest-value Context Runtime gap: every execution profile must be provably assembled through the same kernel contract, while stable prompt head reuse remains visible and testable.

## Problem

Context Runtime already had typed envelopes, leases, probes, policy decisions, API history, TUI, and WebUI panels. The remaining weakness was proof:

- API and conversation synthetic paths still maintained local profile/mode and runtime-header logic.
- UI showed hashes but did not show whether all modes shared the same stable head.
- Tests proved single-envelope cache friendliness, but not all-mode coverage.

## Implementation

- `ContextRuntimeKernel::mode_for_profile()` is the single profile to mode mapping.
- `ContextRuntimeKernel::runtime_header()` builds deterministic semi-stable runtime headers from identity and profile.
- `ContextRuntimeKernel::mode_coverage_report()` synthesizes all required profiles through the same envelope builder and verifies stable-head reuse.
- `ContextRuntimeKernel::cache_stability_report()` converts pairwise envelope comparison into a DTO that explains prompt-cache friendliness.
- Conversation runtime and `/api/context/current` now use the kernel helpers instead of local duplicated mapping/header logic.
- `/api/context/current` returns `mode_coverage` and `cache_stability`.
- WebUI Context panel renders compact mode coverage and cache stability state.

## TDD And Gates

- Runtime tests cover all-profile coverage and dynamic-tail-only cache-friendly changes.
- API tests assert `mode_coverage`, `cache_stability`, and unified runtime header fields.
- WebUI tests assert Mode Coverage rendering and cache-friendly state.

## Acceptance

- MainTurn, SoloGoal, YoloGoal, SubAgent, Collaboration, Review, Resume, and Cron are covered by the same kernel report.
- Dynamic context changes do not break stable-head reuse.
- Runtime/API/UI expose the proof instead of requiring log inspection.
- No background service is required for the unit-level gate.
