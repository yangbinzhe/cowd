# Cowd v0.8.20 Runtime Control Plane And Scenario Kernel Plan

v0.8.20 turns the v0.8.19 runtime control DTO into an active control plane.
The goal is to make Cowd usable beyond coding by binding runtime decisions to
configuration, scenario profiles, task lifecycle, agent delegation, memory
ingestion, UI projection, and measurable gates.

## Design Target

Cowd should behave as a general AI runtime kernel:

- One canonical runtime fact source: SQLite session/task/runtime events.
- One effective control policy per workspace/profile/scenario.
- One context assembly contract across main turns, yolo, sub-agents, review,
  resume, cron, and gateway-triggered work.
- One agent delegation contract with measurable positive lift.
- One memory ingestion and governance path for projects, documents, and work
  records.
- One cockpit surface across TUI/WebUI/API explaining what the runtime decided
  and why.

## Phase 1: Active Runtime Control Config

Add `runtime.control` and `runtime.scenario` to `RuntimeConfig`.

Config shape:

```yaml
runtime:
  scenario: coding
  control:
    enabled: true
    agent:
      enabled: true
      max_parallel_agents: 4
      min_collaboration_score: 50
    task:
      auto_phase_for_yolo: true
      review_after_each_phase: true
      max_failures_before_review: 2
    context:
      preserve_stable_head: true
      yolo_budget_tokens: 12000
      collaboration_budget_tokens: 10000
      review_budget_tokens: 9000
      degrade_on_pressure_bp: 8500
    memory:
      emit_pulses_from_workgraph: true
      review_conflicts: true
      max_candidates_per_turn: 8
```

Scenario defaults:

- `coding`: balanced default, strong verification and collaboration.
- `research`: stronger memory/context budgets, assist-first agents.
- `office`: conservative permissions, concise context, review summaries.
- `ops`: critical review bias, lower failure tolerance.
- `personal`: single-agent first, private memory bias.

Acceptance:

```bash
cargo test -p runtime runtime_control -- --nocapture
cargo test -p runtime config_runtime_control -- --nocapture
cargo test -p cowd-cli runtime_effective_config_exposes_configured_control_policy -- --nocapture
```
