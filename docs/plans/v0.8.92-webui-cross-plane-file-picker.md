# v0.8.92 WebUI Cross-Plane File Picker

Status: implemented
Branch: develop

## Goal

Make WebUI cross-plane file dispatch usable without requiring users to memorize `workspace://file/...` references. The composer remains compact and keeps manual input available for advanced paths.

## Design

- Keep the existing Action Composer as the single WebUI entry point for text, image, and file actions.
- Load workspace files only when `send_file` is selected, so normal Gateway rendering stays cheap.
- Use `/api/workspace/files` as the source of selectable root files.
- Convert a selected file to the canonical resource reference: `workspace://file/<relative-path>`.
- Treat picker failure as a local UI degradation, not a Gateway failure. Users can still enter a path manually.

## Acceptance

- `send_file` exposes a workspace file selector.
- Selecting a file updates the payload field to a canonical workspace reference.
- Preflight and execute requests carry `channel.feishu.send_file` and the selected `resource_ref`.
- WebUI tests cover the selector and request contract.
- Full release gate passes before commit.
