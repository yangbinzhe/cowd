# Matrix MFG WebUI Refactor Status

Status: implementation validated on v0.9.282 baseline.

Active architecture targets:

- Matrix is the structured fact engine kernel.
- Memory is the unstructured fact engine kernel.
- MFG is a manufacturing application built on Matrix, Memory, runtime context, skills and governed actions.
- WebUI registers the MFG page as a pluggable app route at `/apps/mfg`.
- Matrix APIs use `/api/matrix/*`.
- MFG application APIs use `/api/apps/mfg/*`.
- New runtime storage uses `.cowd/matrix.sqlite`.
- `runtime/src/matrix` contains no manufacturing app, UI, or MFG symbols.
- Historical phase scripts and old implementation plans are archived under `docs/archive/`.

Verification gates currently used:

- PASS: `cargo fmt --check`
- PASS: `cargo check -p runtime -p cowd-cli --no-default-features`
- PASS: `cargo test -p runtime capability -- --test-threads=1`
- PASS: `cargo test -p runtime release_gate -- --test-threads=1`
- PASS: `cargo test -p runtime --test matrix_mfg_boundary -- --test-threads=1`
- PASS: `cargo test -p cowd-cli matrix --no-default-features -- --test-threads=1`
- PASS: `npm test` from `webui/`
- PASS: `npm run build` from `webui/`
- PASS: active-source legacy-name scan, excluding archived history and external build/cache directories.
