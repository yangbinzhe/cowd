# v0.9.41 Unified Scenario Gate

## Goal

Move connector/runtime verification from isolated unit checks to a repeatable operator scenario that proves the core daemon path works end to end:

- daemon startup with isolated config and workspace
- HTTP API session creation
- collaborative session lease acquisition and release
- verified identity and persistent grant setup
- connector-aware policy decision
- `mock.docs` commit execution
- durable connector resource indexing
- runtime control-plane projection
- cross-plane audit evidence
- service cleanup after the run

## Scenario

`scripts/v0941_unified_scenario.sh` starts `cowd gateway run` in a temporary tmux session, waits for `/health`, then validates the following chain:

1. `POST /api/sessions`
2. `POST /api/cross-plane/identities`
3. `POST /api/cross-plane/grants`
4. `POST /api/runtime/session-leases/acquire`
5. `POST /api/connectors/services/mock.docs/execute` with `mode=commit`
6. `GET /api/runtime/control-plane`
7. `GET /api/connectors/resources`
8. `GET /api/cross-plane/audit`
9. `POST /api/runtime/session-leases/release`

The script intentionally performs a real grant-backed commit instead of bypassing governance. The expected receipt is `executed`, the policy decision must be `allow`, the connector resource must be persisted, and audit evidence must include connector context.

## Cleanup Contract

The scenario uses only temporary directories under `/tmp` and a tmux session named `cowd-v0941-unified-*`. `EXIT` cleanup kills the tmux session and removes temporary config, HOME, workspace, logs, database, and WebUI symlink state.

On failure, the gateway log is printed to stderr before cleanup so CI and local operators can locate startup or routing failures.

## Acceptance

- Script is repeatable on a clean or dirty workspace.
- No static port collision is ignored; occupied port fails fast.
- Daemon is stopped after success or failure.
- Session lease projection appears in `/api/runtime/control-plane`.
- Connector summary appears in `/api/runtime/control-plane`.
- Connector resources enforce the page clamp and include the scenario resource.
- Cross-plane audit includes connector-aware evidence for `service.mock.docs.read`.
