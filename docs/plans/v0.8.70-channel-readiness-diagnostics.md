# v0.8.70 Channel Readiness Diagnostics

## Goal

Close the channel-management visibility gap without coupling Cowd to live third-party credentials during normal startup or tests.

## Design

Channels are optional infrastructure. They must be visible, auditable, and safely degraded:

- Missing platform config must not block local AI/session/memory workflows.
- Configured channels must expose readiness and missing required fields.
- Credentials must never be returned to API or WebUI clients.
- WebUI Gateway should show channel status before users attempt cross-channel actions.

## Implementation

- Added `/api/platforms` and `/api/platforms/:name` in channel routes.
- Supported `gateway.platforms`, `platform.platforms`, and top-level `platforms`.
- Recognized `platformType` and `platform_type`.
- Added no-secret readiness DTO with status, enabled, configured, credential presence, missing fields, and capabilities.
- Updated WebUI Gateway panel to render platform readiness.

## Acceptance

- No config returns Feishu, WeChat iLink, and WeCom as disabled.
- Missing Feishu `app_secret` reports degraded and does not leak `app_id` or secret values.
- WebUI renders missing fields and capabilities.
