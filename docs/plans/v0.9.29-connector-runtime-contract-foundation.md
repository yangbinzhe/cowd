# v0.9.29 Connector Runtime Contract Foundation

## Version Goal

Build the minimal connector runtime contract that lets Cowd describe external accounts, capabilities, and resources before real service connectors are added.

This version deliberately avoids real Feishu/GitHub/Notion calls. It creates the source-of-truth models and management API that later versions will use.

## Current Gap

Cowd already has `CrossPlaneAction`, policy decisions, grants, audit records, execution receipts, channel dispatch, WebUI Gateway composer, and TUI Gateway projection.

The missing contract is:

- which provider account exists,
- which capability is available,
- which plane owns the capability,
- which scopes are required,
- which external resources are known,
- how these facts appear in the runtime control-plane.

## Scope

Implement:

- `ProviderAccount`
- `CapabilityManifest`
- `ExternalResourceRef`
- `ConnectorRegistrySnapshot`
- default registry with current channel/cross-plane capabilities
- connector management API:
  - `GET /api/connectors/summary`
  - `GET /api/connectors/accounts`
  - `GET /api/connectors/capabilities`
  - `GET /api/connectors/resources`
- runtime control-plane connector projection
- targeted tests

## Non-goals

- No real service connector execution.
- No OAuth/token lifecycle.
- No persistent ResourceDirectory database.
- No UI redesign.
- No Feishu write operation.

## TDD Plan
