# v0.8.90 Cross-Plane Local Payload Safety

## Goal

Make media/file dispatch usable without opening an unsafe local file escape.
v0.8.89 added typed media dispatch; this version adds the execution-time
workspace boundary required before user-facing file composition is expanded.

## Design

- Policy planning remains platform-agnostic and does not know about the Cowd
  workspace.
- API commit execution resolves non-text local payloads against `AppState`
  `workspace_root`.
- Remote image URLs remain allowed.
- Remote file/document URLs are blocked until a service-side download/import
  flow exists.
- Local image/file payloads must resolve to an existing regular file inside the
  active workspace.
- Absolute paths are allowed only if their canonical path is still inside the
  workspace.
- Blocked payloads produce a dispatch outcome and blocker instead of reaching
  the adapter.

## Implemented

- Added local payload resolution to cross-plane commit dispatch.
- Added support for `workspace://file/` and `workspace://changed-file/` payload
  references.
- Added API tests for:
  - workspace-relative file dispatch reaching the adapter with canonical path
  - outside-workspace file dispatch being blocked before adapter invocation

## Validation

- `cargo fmt --all`
- `cargo test -p cowd-cli cross_plane_execute_commit_ -- --nocapture`
