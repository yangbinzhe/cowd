# v0.9.51 Resource Memory Promotion Dedup

## Goal

Make connector resource promotion idempotent so repeated TUI/WebUI/API actions do not create duplicate L3 memories for the same external resource.

## Scope

- Reuse an existing L3 connector-resource memory when it already contains the exact resource `ref: ...` line.
- Return a replay receipt with the existing `memory_id`.
- Fail closed if the deduplication scan cannot complete, avoiding silent duplicate memory creation under uncertain state.
- Extend the existing metadata-only promotion API test to verify repeated promotion produces one memory entry.

## Validation

- `cargo test -p cowd-cli connector_resource_promote_memory_creates_metadata_only_memory --no-default-features`
- `cargo fmt --check`
- `git diff --check`
