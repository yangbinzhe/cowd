# v0.9.64 Real Unified Runtime Surface Scenario

## 目标

在不使用 mock API 的前提下，补齐 TUI、WebUI、daemon、HTTP API、session lease、task、memory、connector summary 的真实联合场景门。该版本验证系统作为一个整体运行，而不是只验证单个模块。

## 实施内容

- 新增 `scripts/v0964_unified_runtime_surface_scenario.sh`。
- 新增 `webui/unified-runtime.live.e2e.spec.js`。
- 场景脚本启动真实 gateway daemon，并使用临时生产形态目录：
  - `COWD_CONFIG_HOME`
  - workspace `.cowd`
  - SQLite task/session/memory state
  - Unix socket daemon control
- 场景脚本启动真实 TUI tmux 会话，通过 `--session` attach 到同一个 daemon session。
- Playwright 浏览器连接真实 WebUI 静态页和真实 API，不拦截 `/api/**`。
- WebUI 通过真实 API 创建 task phase/artifact/review，并验证 runtime、agents、memory、gateway panel。
- 脚本最后校验 API JSON 与 SQLite 持久化结果，并清理 tmux/临时目录。

## 非目标

- 不使用 `mock.docs` 执行路径。
- 不默认调用外部生产渠道写操作。
- Feishu 等真实外部 connector 只在设置 `COWD_V0964_REAL_CONNECTOR_PROVIDER=feishu.readonly` 且本地配置可用时执行只读工具探测。

## 验收

```bash
CARGO_TARGET_DIR=/tmp/cowd-v0964-target scripts/v0964_unified_runtime_surface_scenario.sh
```

通过标准：

- TUI 捕获到 daemon control connected、session attached/created、lease acquired。
- WebUI Runtime Console 展示同一个 session lease。
- WebUI Agents 展示真实 task phase/artifact/review。
- WebUI Memory panel 展示真实 memory status。
- WebUI Gateway panel 展示真实 connector console。
- `/api/runtime/control-plane`、`/api/runtime/session-leases`、`/api/tasks`、`/api/memory/status`、`/api/connectors/summary` 全部返回可验证状态。
- `tasks.db` 中存在该场景任务与 review 结果。
- 脚本退出后无遗留 tmux session 或临时目录。
