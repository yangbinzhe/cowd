# v0.8.64 Runtime Platform Baseline

Status: active
Branch: develop
Baseline evidence date: 2026-06-07
Previous implementation baseline: 0.8.63

## Objective

v0.8.64 is a platform-baseline convergence release. Its purpose is to turn the current large `develop` worktree into a reviewed, testable, and committable product baseline before deeper Agent Collaboration and Channel Work System releases continue.

The version must preserve the broad v0.8.9+ architecture direction while making the current implementation operationally defensible:

- Session and Context are stable runtime infrastructure.
- Memory remains connected to session/context/agent flows and does not regress into a static store.
- Runtime Control Plane is the shared operational fact surface for API, WebUI, TUI, doctor, logs, and release checks.
- TUI and WebUI expose useful control actions, not only read-only diagnostics.
- Full release gate is the acceptance boundary, including Rust, WebUI, browser E2E, tmux/service scenarios, logs, DB checks, and cleanup.

## Non-Negotiable Invariants

1. JSONL is not a default runtime session store.
2. Local `.jsonl/.json` remains allowed only through explicit import/export and legacy codec tests.
3. SQLite is the managed runtime session source of truth.
4. Failed optional capabilities must degrade locally and must not crash daemon startup, TUI render, or control-plane inspection.
5. Provider configuration must never leak API keys through API responses, logs, TUI notifications, or WebUI panels.
6. Release verification must leave no test ports, test tmux sessions, build targets, or generated UI test residue.
