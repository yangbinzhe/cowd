# v0.9.33 MCP Connector Control Plane

## Goal

Bring configured MCP servers into the connector runtime contract without making runtime control-plane inspection start or block on external MCP processes.

## Delivered

- Added MCP server/tool/resource mapping helpers in `runtime::connector`.
- Added canonical `mcp://` external resource refs.
- Added MCP capability counts to connector summaries.
- Projected configured `mcpServers` into connector accounts and server capabilities.
- Redacted MCP config values by projecting only secret refs and readiness metadata.

## Validation

- `cargo test -p runtime connector`
- `cargo test -p cowd-cli connector`
- `cargo fmt --check`
- `git diff --check`

## Design Notes

- Live MCP discovery remains outside the synchronous control-plane snapshot.
- A broken MCP config degrades only the MCP account/capability surface and does not block daemon, session, TUI, or WebUI runtime status.
