# v0.9.63 TUI Render Bridge Quality Gate

## 目标

收敛 legacy `App` 到新 TUI component 渲染路径的桥接风险，建立可重复执行的 TUI 交互质量门，验证 runtime command center 的核心状态确实从 App 投射到最终 TUI 画面。

## 实施内容

- 新增 state-level render contract 测试：
  - `render_bridge_projects_runtime_command_center_to_gateway_tab`
  - 覆盖 App runtime fields、memory status、action receipts、connector resources 到 Gateway tab 的最终渲染。
- 保留并纳入质量门：
  - `renders_every_sidebar_tab_in_wide_and_compact_layouts`
  - `render_shows_connector_console_state`
- 新增脚本 `scripts/v0963_tui_interaction_quality_gate.sh`：
  - 默认运行无外部服务依赖的 TUI 渲染质量门。
  - 设置 `COWD_TUI_RUN_TMUX_SMOKE=1` 时再执行真实 tmux smoke。

## TDD 验收

1. Gateway tab 渲染必须包含 `Core Runtime`、`AI Context`、`Work Control`、`Connector Plane`。
2. App 中的 memory/action receipt/connector resource 必须出现在最终 buffer。
3. 全 sidebar tab 在宽屏和紧凑宽度都不能空白或 panic。
4. `cargo fmt --check` 与 `git diff --check` 必须通过。

## 评价标准

- legacy App bridge 的关键路径有可执行 contract。
- TUI 交互质量门可被 release gate 或人工回归复用。
- 默认质量门不依赖 tmux/外部服务，真实 smoke 保持按需开启。
