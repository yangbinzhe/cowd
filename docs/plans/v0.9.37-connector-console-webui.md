# v0.9.37 Connector Console WebUI

## Goal

Upgrade the WebUI Gateway panel into a connector console backed by runtime APIs only.

## Delivered

- Added WebUI connector API methods for summary, accounts, capabilities, resources, service tools, and service execution.
- Added a Connector Console section inside Gateway with:
  - Accounts
  - Capabilities
  - Services
  - Resources
  - Receipts / Audit
  - Health and degraded reasons
- Added resource search and fixed page offsets.
- Added service execution controls for:
  - `mock.docs`
  - `feishu.readonly`
- Kept WebUI as a control-plane consumer. It does not touch adapters or service clients directly.

## Validation

- `npm test -- modules.test.js`
- `npm run test:e2e -- connector-console.e2e.spec.js`
- `cargo test -p cowd-cli connector`
- `cargo fmt --check`
- `git diff --check`

## Design Notes

- The console is embedded in Gateway because Gateway already owns cross-plane and channel control.
- Connector rows reuse the existing audit row vocabulary to keep the panel compact and operational.
- Connector endpoint failures degrade the console section only and do not block WeChat authorization or platform readiness rendering.
