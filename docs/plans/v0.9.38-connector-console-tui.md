# v0.9.38 Connector Console TUI

## Goal

Bring connector runtime visibility into the TUI Gateway panel and command palette.

## Delivered

- Extended daemon projection client with connector resource/account/capability endpoints.
- Extended runtime control snapshot with connector accounts, capabilities, resources, and degraded reasons.
- Propagated connector projection state into `App`.
- Added GatewayPanel connector sections:
  - Connector account status
  - Connector capabilities
  - Connector resources
  - Connector degraded reasons
- Added connector endpoints to the TUI Gateway API contract list.
- Added dynamic command palette entries for:
  - Search Connector Resources
  - Probe Connectors
  - Mock Docs Dry Run
  - Mock Docs Commit
  - Inspect Degraded Connector

## Validation

- `cargo test -p cowd-cli gateway_panel --no-default-features`
- `cargo test -p cowd-cli runtime_control_store --no-default-features`
- `cargo test -p cowd-cli command_palette --no-default-features`
- `cargo test -p cowd-cli projection_client --no-default-features`
- `cargo fmt --check`
- `git diff --check`

## Design Notes

- The TUI does not directly call adapters or service clients from the panel.
- Connector failures degrade connector visibility only; they do not break the main input state.
- Service execution from the command palette remains routed through existing slash/control entries until TUI has a dedicated async connector execution action.
