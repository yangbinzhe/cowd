# v0.9.56 Same Session Multi-Surface Sync

## Goal

Verify that daemon socket clients, HTTP API/WebUI clients, and the shared daemon runtime observe the same session, lease, and task state.

## Scope

- Add a live scenario that starts an isolated gateway daemon.
- Use the Unix socket protocol to create/attach a session, acquire a collaborative lease, and start a task.
- Use HTTP API routes to verify the same session lease and task are visible from the projection surface.
- Keep the scenario browser-free so it is fast and stable; WebUI consumes the same HTTP projection contract.
