# v0.9.70 Gateway/WebUI Contract

## Target

Unify the daemon browser access layer so users can clearly distinguish:

- daemon: the runtime-owning background process.
- gateway: the HTTP/SSE access layer embedded inside the daemon.
- API router: the gateway's internal route table.
- static WebUI: the browser console served by the gateway.
- socket control: the local low-latency daemon control plane used by TUI/CUI.

## Implemented

- Added `gateway_static` for explicit WebUI static source resolution.
- Added `gateway_health` for `/healthz` and `/readyz` snapshots.
- Added `gateway_service` for `/api/webui/manifest`.
- Kept legacy `/health` unchanged for compatibility.
- Added static WebUI SPA fallback so refreshing a deep link returns `index.html`.
- Added WebUI API methods for gateway health, readiness, and manifest.
- Added a live tmux/curl scenario for gateway health, readiness, manifest, static assets, and deep-link refresh.
