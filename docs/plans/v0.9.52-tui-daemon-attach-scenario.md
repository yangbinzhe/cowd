# v0.9.52 TUI Daemon Attach Scenario

## Goal

Verify that a newly launched TUI can attach to an already running daemon, acquire a collaborative session lease, and render daemon projection state without relying on daemon autostart or the default global socket.

## Scope

- Add `COWD_DAEMON_SOCKET` support for daemon run and TUI control clients.
- Keep `/tmp/cowd.sock` as the default for normal operator use.
- Add a tmux-backed live scenario that starts a gateway on an isolated HTTP port and Unix socket, persists a connector resource, launches TUI in a pty, and captures the first screen.
- Fail on missing daemon connection, missing session attach/lease, panic, or unexpected TUI startup failure.
