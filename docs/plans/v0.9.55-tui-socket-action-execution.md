# v0.9.55 TUI Socket Action Execution

## Goal

Move high-frequency TUI task and approval operations to the daemon Unix socket fast path while preserving HTTP projection fallback for compatibility.

## Scope

- Add socket commands for task list/start/cancel/complete.
- Add socket commands for approval pending/respond.
- Make TUI runtime snapshot enrichment prefer socket task/approval data before HTTP.
- Make TUI command-palette task and approval actions execute through socket first, falling back to HTTP.
- Keep WebUI/API routes unchanged.

## Validation

- `cargo test -p cowd-cli task_control_client_sends_socket_commands --no-default-features`
- `cargo test -p cowd-cli approval_control_client_sends_socket_commands --no-default-features`
- `cargo test -p cowd-cli snapshot_extracts_projection_summaries --no-default-features`
