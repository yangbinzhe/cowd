# v0.9.97 IACC WebUI Report Visibility

## Goal

`v0.9.97` exposes IACC cockpit report delivery state in the WebUI. Operators can
inspect IACC health, load a report by id, see delivery classification and latest
receipts, and trigger a governed force retry without dropping into raw curl.

## Scope

- Add WebUI API methods for:
  - IACC health;
  - cockpit report fetch;
  - report delivery-state fetch;
  - report delivery retry;
  - report schedule run.
- Add an `IACC` right-panel tab.
- Add `Panels.renderIacc`.
- Render report status, cadence, owner, profile, delivery ref, attempt count,
  classification, retry posture, latest receipt, and recent delivery receipts.
- Add a compact force retry control that calls the existing retry API.
- Advertise `cockpit_report_webui_visibility` in IACC health.

## Design Notes

This is a dense operator panel, not a dashboard hero. The panel reuses existing
Cowd WebUI primitives:

- `panel-section`;
- `memory-metrics`;
- `panel-item`;
- `connector-row`;
- `memory-chip`.

No new decorative visual language was introduced.

## Acceptance

- WebUI unit tests verify the IACC API route contract.
- WebUI unit tests verify the IACC panel renders health, report state, latest
  receipt, and force retry payload.
- `scripts/v0997_iacc_webui_report_visibility_scenario.sh` validates static
  WebUI exposure and backend health capability.

## Next Version

`v0.9.98` should produce the production operation package: rollout checklist,
