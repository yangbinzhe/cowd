# Cowd v0.8.10 AI Capability Framework Plan

## 目标

v0.8.10 的目标是把 v0.8.9 已经打通的 TUI/WebUI/API/Memory/Session 能力继续收敛成更高阶的 AI 能力框架：

- SessionKernel 成为会话生命周期、热 runtime、持久化消息、事件流、审计状态的统一服务边界。
- Memory 不只“能写入”，而要稳定参与上下文准备、会话恢复、长期任务连续执行和 UI 可解释展示。
- TUI/WebUI 不再各自拼状态；所有入口共享同一核心能力模型、同一事件语义、同一失败恢复策略。
- Release gate 从“当前可过”升级为“持续可守”，每个专项都要有自动化、场景化、清理检查。

## 当前 0.8.10 专项

### Phase 1: SessionKernel 内核化

目标：

- 新增 `SessionKernel` 服务层，封装 `ActiveSessions + UnifiedSessionStore + SessionEventBus`。
- API/TUI/daemon 不再直接散落组合三套对象；新代码必须从 Kernel 获取 session registry、store、event bus。
- Session create/list/detail/messages/events/delete/compact/switch 以 UnifiedSessionStore 为持久事实源，ActiveSessions 只保留热 runtime。

验收：

- `cargo test -p cowd-cli api_routes -- --nocapture`
- `cargo test -p cowd-cli cli_session_sync_replaces_store_messages_and_events -- --nocapture`
- 新增 Kernel 单测覆盖构造、热/冷事实源访问、event bus 共享。

### Phase 2: SessionStore deprecated 迁移

目标：

- 消除 release gate 中项目自身 deprecated warning。
- 外部测试 fixture 不再使用 `runtime::SessionStore`。
- 旧 `runtime::session_control` 只作为明确兼容层保留，不能再被 cowd-cli 新测试或主链路依赖。

验收：

- `cargo test -p cowd-cli --test resume_slash_commands resume_latest_restores_the_most_recent_managed_session -- --nocapture`
- `cargo test -p cowd-cli api_routes -- --nocapture` 不再出现 `resume_slash_commands` deprecated warning。

### Phase 3: Memory 实战化

目标：

- 识别 memory 初始化、TUI 启动、prepare_context、session hydration 的阻塞和降级路径。
- TUI/WebUI 可展示 memory enabled/disabled/degraded、最近写入、召回来源、token 节省估算。
- 长任务连续执行时，memory 参与“目标、决策、未完成任务、失败恢复”四类上下文。

验收：

- Memory prepare/performance gate 继续通过。
- 新增 degraded memory 启动测试，证明 memory 异常不会阻塞 TUI 首屏。

### Phase 4: Interaction Model 对齐 Codex/OpenCode/Hermes

目标：

- TUI 首页必须快速可见：模型、模式、session、permission、memory、tools、任务状态。
- `--yolo`/连续执行模式必须在 UI、system prompt、status、release smoke 中一致可见。
- 所有长任务具备进度、取消、恢复、审计。

验收：

- `scripts/tui_smoke.sh`
- TUI component tests
- tmux 清理检查

### Phase 5: Release Gate 2.0

目标：

- `make release-gate` 继续作为本地发布门禁。
- 对每个新增专项增加最小但真实的自动化或场景化测试。
- 门禁必须清理浏览器服务、tmux、测试端口。

验收：

- `make release-gate`
- 端口残留检查为空。
- tmux 残留检查为空。

## 完成定义
