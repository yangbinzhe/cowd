# v0.8.69 Memory Local Semantic Bridge

## Goal

Close the remaining memory recall test debt where the suite still proved that semantic-only queries could not find related memories.

## Design

Cowd already supports remote embedding configuration and has a hybrid search abstraction, but the default local path must remain fast and offline. This version adds a narrow, deterministic semantic bridge:

- Runs only when FTS/vector recall returns fewer results than the L3 target.
- Expands a bounded set of high-value concept families into local FTS query variants.
- Does not call remote embedding services.
- Does not replace future vector search; it removes the most obvious local recall blind spot.

## Implementation

- Added `search::semantic_bridge`.
- Integrated bounded semantic variants into `DeepLayer::recall`.
- Converted the old RED test into a positive recall test for `machine vision inference` -> neural network/classification memories.

## Acceptance

- Local recall can find related memory without direct keyword overlap.
- Existing FTS recall and prepare-context cache behavior remain intact.
- Performance benchmarks and LongMemEval must continue passing.
