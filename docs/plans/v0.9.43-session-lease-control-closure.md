# v0.9.43 Session Lease Control Closure

## Goal

Close the first remaining TUI/WebUI/daemon alignment gap by making session lease ownership visible and controllable from the WebUI Runtime Console and the TUI HTTP projection client.

## Changes

- Added WebUI API methods for:
  - `GET /api/runtime/session-leases`
  - `POST /api/runtime/session-leases/acquire`
  - `POST /api/runtime/session-leases/release`
- Added Runtime Console lease section with active owner/mode/session rows.
- Added Runtime Console acquire/release controls for the current WebUI session.
- Added TUI projection client methods for HTTP acquire/release.
- Added WebUI and Rust tests for the lease route contracts.

## Acceptance

- WebUI can show active daemon session leases.
- WebUI can acquire and release a collaborative lease for its current session.
- TUI projection client can call the same HTTP lease control routes.
- Existing unified daemon scenario remains valid.
