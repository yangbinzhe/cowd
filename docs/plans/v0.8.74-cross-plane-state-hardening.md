# v0.8.74 Cross-Plane State Hardening

## Goal

Close the control-plane persistence and long-running stability gap. Cross-plane
state must survive process interruption during save and must not grow audit
records without bound.

## Scope

- Save control-plane snapshots through a temporary file followed by rename.
- Remove temporary files on failed replacement.
- Bound in-memory audit records to the newest 10,000 records.
- Preserve the existing JSON snapshot format.

## Acceptance

- Saved state round-trips through the same JSON snapshot loader.
- Successful saves leave no temporary state files.
- Audit history retains recent records and drops only the oldest overflow.
- Existing API and UI behavior is unchanged.

## Validation

- Runtime unit tests cover atomic save and audit bounding.
- Release gate must pass before commit.
