# v0.8.79 Cross-Plane WebUI Execution Visibility

## Goal

Expose the new cross-plane execution substrate in the WebUI so operators can
see whether an action is blocked by policy, platform readiness, adapter support,
adapter binding, or idempotent replay history.

## Design

- Gateway panel shows adapter capabilities.
- Gateway panel shows recent execution receipts.
- The display stays read-only and compact.
- Capability rows distinguish `live supported` from `plan only`.
- Receipt rows show status, dispatch status, mode, and idempotency key.

## Acceptance

- WebUI contract includes adapter and execution endpoints.
- Gateway panel renders adapter capability rows.
- Gateway panel renders execution receipt rows.
- Existing Gateway platform readiness and policy evidence remain visible.
