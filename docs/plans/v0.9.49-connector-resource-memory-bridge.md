# v0.9.49 Connector Resource To Memory Bridge

## Goal

Let operators promote connector resource metadata into the memory substrate without importing external document bodies implicitly.

## Scope

- Add `POST /api/connectors/resources/promote-memory`.
- Store an L3 `Reference` memory entry with resource title, canonical ref, provider, type, state, permissions, and metadata-only body policy.
- Add WebUI `Remember` action on connector resources.
