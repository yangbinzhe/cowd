# v0.9.34 ResourceDirectory Durable Store

## Goal

Promote connector resources from process-local memory into a recoverable SQLite-backed directory.

## Delivered

- Added `SqliteResourceDirectory` with schema initialization.
- Added durable `upsert`, `get`, `list_page`, `list_recent`, `search`, `mark_indexed`, `mark_stale`, and `attach_source`.
- Switched connector resource API to `workspace/.cowd/resource-directory.sqlite`.
- Preserved degraded fallback behavior when the resource directory cannot be opened.
- Persisted `mock.docs` resource refs through the connector service execution route.

## Validation

- `cargo test -p runtime connector`
- `cargo test -p cowd-cli connector`
- `cargo fmt --check`
- `git diff --check`

## Design Notes

- The old in-memory `ResourceDirectory` remains available as a lightweight fallback/test primitive.
- API route failures return degraded resource state instead of failing the whole connector or runtime control-plane.
- Resource APIs support `q`, `limit`, and `offset` so later large-resource work can avoid full-list rendering.
