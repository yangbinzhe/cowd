# v0.9.88 IACC Scale Benchmark

## Goal

Add a repeatable benchmark for the first high-volume server-manufacturing data
shape: many component/week facts flowing into the metric dependency graph and
incremental compute jobs.

This version is intentionally measurement-first. It does not introduce an
external OLAP or streaming engine yet. It gives the project a baseline for
deciding when SQLite/local compute is no longer enough.

## Benchmark Shape

Default scenario:

- seed the server manufacturing domain pack;
- generate 20 scale components;
- generate 52 weekly supply shortage facts per component;
- ingest 1040 generated facts in one batch;
- plan a compute job for `supply.material_shortage`;
- run scoped recompute through the affected metric ids;
- verify unrelated metrics such as `work_center_load` are not recomputed by this
  supply-triggered job.

The script can be tuned:

```text
COWD_V0988_PRODUCTS=20
COWD_V0988_WEEKS=52
COWD_V0988_INGEST_LIMIT_MS=120000
COWD_V0988_COMPUTE_LIMIT_MS=120000
```

## Scenario Script

```text
scripts/v0988_iacc_scale_benchmark.sh
```

The script writes a benchmark summary inside the temporary workspace:

```text
.cowd/iacc-v0988-scale-benchmark.json
```

## Acceptance

The benchmark passes when:

1. gateway exposes schema version 8;
2. domain seed succeeds;
3. generated fact count equals `products * weeks`;
4. batch ingest succeeds;
5. compute job plans affected metrics through metric dependencies;
6. compute job completes and produces at least the generated fact count worth of
   metric states;
7. unrelated work-center metric state remains absent;
8. ingest and compute duration stay under configured limits.
