# v0.8.94 TUI Dynamic Slash Completion

Status: implemented
Branch: develop

## Goal

Remove the stale TUI prompt command snapshot and make slash-command completion follow the central command registry. This keeps TUI interaction aligned as new AI runtime, gateway, session, memory, and agent commands are added.

## Design

- Use `commands::slash_command_specs()` as the single source of truth for TUI slash completion.
- Include both canonical command names and registered aliases.
- Deduplicate through an ordered set for deterministic completion output.
- Preserve frecency ranking and existing max-suggestion behavior.

## Acceptance

- `/sta` still suggests `/status` and `/stats`.
- Registered aliases such as `/marketplace` and `/skill` appear without manual TUI updates.
- Static command snapshot is removed from the prompt component.
- TUI prompt tests and release gate pass.
