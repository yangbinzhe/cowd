# v0.8.72 Cross-Plane Identity Resolution

## Goal

Close the identity equivalence gap for cross-channel permissions. The control
plane must resolve external channel identities into a canonical principal before
approval or grant decisions are applied.

## Scope

- Add identity resolution to the cross-plane control plane.
- Prefer exact identity references over inferred contact-key matches.
- Support email and explicit phone/mobile/tel keys without granting permission
  automatically.
- Expose HTTP identity resolution for TUI/WebUI/channel callers.
- Show identity bindings in the WebUI gateway panel.

## Acceptance

- A Feishu identity binding with a verified email can resolve a WeChat identity
  that carries the same email.
- Exact identity refs take precedence over contact-key matches.
- Resolution returns principal, trust, binding id, matched ref, and match kind.
- No grant or permission is created by identity resolution.

## Validation

- Runtime unit tests cover exact and contact-key resolution.
- API tests cover create identity then resolve cross-channel identity.
- WebUI module tests cover the route contract and gateway identity display.
- Release gate must pass before commit.
