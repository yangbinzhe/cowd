# v0.9.58 TUI Socket Connector/Resource Control

## Goal

Move high-frequency TUI connector resource operations to the daemon Unix socket fast path while keeping HTTP projection/API routes for WebUI and remote clients.

## Scope

- Add daemon socket commands for connector resource listing, resource revalidation, and resource-to-memory promotion.
- Add `DaemonControlClient` methods for those commands.
- Make TUI connector resource actions use socket first and HTTP projection fallback second.
- Keep resource persistence, memory dedup, and HTTP behavior unchanged.

## Validation

- `cargo test -p cowd-cli connector_resource_control_client_sends_socket_commands --no-default-features`
- `cargo test -p cowd-cli connector_resource_actions_prefer_socket_control --no-default-features`
- `cargo test -p cowd-cli connector_resource_promote_memory_creates_metadata_only_memory --no-default-features`
- `cargo fmt --check`
- `git diff --check`
