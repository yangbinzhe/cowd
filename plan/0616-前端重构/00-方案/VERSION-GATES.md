# 版本门禁

## 通用门禁

每个版本必须完成：

- 版本计划文件。
- TDD 测试变更。
- 实现代码。
- 自动测试。
- 视觉截图。
- 测试报告。
- 单独提交。

## 视觉截图矩阵

默认截图尺寸：

- Desktop：1440x900
- Laptop：1280x800
- Tablet：768x1024
- Mobile：390x844

第一阶段至少输出 Desktop 与 Mobile，后续页面迁移阶段按页面增加。

## 报告字段

每个报告至少包含：

- 版本号。
- 目标。
- 代码改动。
- 测试命令。
- 测试结果。
- 截图路径。
- 未完成项。
- 下一版本衔接。
