# v0.9.207 Skills + Agents + Tools 页面计划

## 目标

将能力管理相关页面统一为页面级工作台：

1. Skills：技能投影、运行历史、列表可扫描。
2. Agents：任务、阶段、workgraph、验收状态可扫描。
3. Tools：工具注册表、配置和说明可扫描。

## 验收标准

1. `cd webui && npm test` 通过。
2. `cd webui && npm run test:e2e -- webui-shell.e2e.spec.js` 通过。
