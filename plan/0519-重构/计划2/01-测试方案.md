# Cowd 计划2 — 测试方案

> 测试金字塔：单元 60% | 集成 30% | E2E 10%
> 目标覆盖率：核心模块 80%，总项目 65%

## 一、测试金字塔

```
           ┌──────────────┐
           │  E2E (10%)   │ ← 完整 CLI/TUI/Server 会话（8 场景）
          ┌┴──────────────┴┐
          │  集成 (30%)    │ ← 组件交互 + API 测试（20 场景）
         ┌┴────────────────┴┐
         │   单元 (60%)      │ ← 每个模块独立测试（60+ 场景）
        └───────────────────┘
```

## 八、执行清单（Checklist）

每个 Phase 完成后必须通过：

- [ ] `cargo fmt --all -- --check`
- [ ] `cargo clippy --workspace --all-targets`
- [ ] `cargo test -p <crate>` (阶段相关的 crate)
- [ ] `cargo test --workspace` (全量，Phase 8 后)
- [ ] `cargo build --release` 成功
- [ ] 新增代码有 rustdoc 注释
- [ ] 相关文档已更新

### 编译验证

```bash
# 每个 Phase 完成后运行
cargo check --workspace 2>&1 | wc -l  # 应为 0 errors

# 全量测试
cargo test --workspace 2>&1 | grep "test result"
```
