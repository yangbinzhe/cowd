# 目标架构：现代化 TUI 终端控制设计

> 版本：v1.0 | 日期：2026-05-18

## 1. 核心设计原则

1. **事件驱动**：所有 API 事件（文本、思考、工具、错误）通过 channel 流入 TUI 渲染循环
2. **流式优先**：文本逐字符追加，工具状态实时更新，无阻塞等待
3. **能力对等**：TUI 承载 Server 全部能力（SSE event → ratatui widget）
4. **零 stdout 泄漏**：渲染管线 100% 经 ratatui，无任何 `println!`/`write!(stdout)`
5. **会话安全**：Session clone 清除 persistence，仅在提交点原子写入

## 3. 核心组件设计

### 3.1 TuiEvent 事件系统

```rust
/// 所有从 runtime 流向 TUI 的事件
#[derive(Debug, Clone)]
pub enum TuiEvent {
    // ── 流式内容 ──
    TextDelta { text: String },
    ThinkingDelta { thinking: String },
    ThinkingComplete,

    // ── 工具生命周期 ──
    ToolStart { id: String, name: String, preview: String },
    ToolProgress { id: String, name: String, progress: String },
    ToolComplete { id: String, name: String, summary: String, exit_code: Option<i32> },

    // ── 统计信息 ──
    TokenUsage { input: u64, output: u64, cache_create: u64, cache_read: u64 },
    CostEstimate { cost_usd: f64 },

    // ── Turn 状态 ──
    TurnStarted,
    TurnComplete { summary: TurnSummaryData },
    TurnError { error: String },

    // ── 系统 ──
    CompactionNotice { removed_count: usize },
    Heartbeat,
}

struct TurnSummaryData {
    message_count: usize,
    iterations: u32,
    token_usage: TokenUsage,
    total_cost: f64,
    assistant_text: String,
}
```

### 3.2 StreamingTurnRunner（后台线程）

```rust
/// 在独立线程中执行一次 turn，通过 channel 通知 TUI
pub struct StreamingTurnRunner {
    tui_tx: mpsc::Sender<TuiEvent>,
    session: Session,
    model: String,
    system_prompt: Vec<String>,
}

impl StreamingTurnRunner {
    pub fn spawn(
        input: String,
        session: Session,              // 移除了 persistence 的 clone
        model: String,
        system_prompt: Vec<String>,
        tui_tx: mpsc::Sender<TuiEvent>,
    ) -> thread::JoinHandle<Result<TurnOutcome, RuntimeError>> {
        thread::spawn(move || {
            // 创建不带 persistence 的 runtime
            let session = session.without_persistence();

            // 构建 runtime（tokio context 内）
            let rt = tokio::runtime::Builder::new_current_thread()
                .enable_all()
                .build()?;

            rt.block_on(async {
                let mut conv = ConversationRuntime::new_with_callbacks(
                    session,
                    api_client,
                    tool_executor,
                    TuiToolCallback::new(tui_tx.clone()),
                );

                tui_tx.send(TuiEvent::TurnStarted).ok();

                let result = conv.run_turn_streaming(&input, |event| {
                    // 实时转发所有流事件
                    tui_tx.send(TuiEvent::from_api_event(event)).ok();
                }).await;

                match result {
                    Ok(summary) => {
                        tui_tx.send(TuiEvent::TurnComplete { summary: summary.into() }).ok();
                        Ok(TurnOutcome::Success { session: conv.into_session(), summary })
                    }
                    Err(e) => {
                        tui_tx.send(TuiEvent::TurnError { error: e.to_string() }).ok();
                        Err(e)
                    }
                }
            })
        })
    }
}
```

### 3.3 TuiToolCallback（工具进度回调）

```rust
/// 实现 runtime::ToolCallback，将工具事件转为 TuiEvent
pub struct TuiToolCallback {
    tui_tx: mpsc::Sender<TuiEvent>,
}

impl ToolCallback for TuiToolCallback {
    fn on_tool_start(&self, id: &str, name: &str, preview: &str) {
        self.tui_tx.send(TuiEvent::ToolStart {
            id: id.to_string(),
            name: name.to_string(),
            preview: preview.to_string(),
        }).ok();
    }

    fn on_tool_progress(&self, id: &str, name: &str, progress: &str) {
        self.tui_tx.send(TuiEvent::ToolProgress {
            id: id.to_string(),
            name: name.to_string(),
            progress: progress.to_string(),
        }).ok();
    }

    fn on_tool_complete(&self, id: &str, name: &str, result_summary: &str, exit_code: Option<i32>) {
        self.tui_tx.send(TuiEvent::ToolComplete {
            id: id.to_string(),
            name: name.to_string(),
            summary: result_summary.to_string(),
            exit_code,
        }).ok();
    }
}
```

### 3.4 会话安全模型

```
Session 生命周期（修复后）:

1. create_session() → persistence = Some(SessionPersistence { path })
                       ↑ 仅根 session 有 persistence

2. prepare_for_turn():
   turn_session = root_session.without_persistence()  ← 新方法，清除 persistence
   
3. turn 执行期间:
   turn_session.push_message() → 仅内存操作，不写入文件
   
4. turn 成功 → commit:
   root_session.messages = turn_session.messages  ← 整批替换
   root_session.save_to_path()                    ← 一次原子写入
   
5. turn 失败 → discard:
   turn_session 丢弃，root_session 不变
```

**关键方法**：
```rust
impl Session {
    /// 创建一个无持久化的副本（用于一次 turn）
    pub fn without_persistence(&self) -> Self {
        let mut clone = self.clone();
        clone.persistence = None;
        clone
    }
}
```

### 4.2 渲染性能设计

```
极速流式输出策略:

1. 事件批处理：
   - TUI 事件循环以 ~16ms (60fps) 间隔运行
   - 每帧收集所有积压的 TuiEvent
   - 批量更新 app state → 一次 ratatui draw

2. 渲染去抖：
   - 流式文本：累积 ≥ 100 字符或 ≥ 50ms 后才触发重绘
   - 工具卡片：创建/更新立即重绘
   - 状态栏：token/cost 变化时重绘（去抖 200ms）

3. Diff 友好：
   - 流式文本追加到最后一个消息块，不重新构建整个 Line 列表
   - 工具卡片使用固定高度的预计算布局
   - 滚动区域使用虚拟行索引（仅渲染可见行）

4. 内存管理：
   - 消息历史使用 ring buffer（保留最近 500 条）
   - 工具输出截断到 200 行
   - Thinking 内容截断到 5000 字符（可展开）
```
